# cookies.txt для загрузчика

Маленькое расширение браузера: сохраняет cookies открытого сайта в файл
`cookies.txt` (формат Netscape), который понимает **Video Downloader**.
Нужно для видео 18+ и закрытых аккаунтов.

Расширение **ничего не отправляет в интернет** — в его коде нет ни одного
сетевого запроса. Файл сохраняется только на ваш компьютер.

## Что оно делает
- Кнопка сохраняет cookies текущей вкладки в файл, названный по площадке:
  `TikTok.txt`, `YouTube.txt`, `Instagram.txt`, `X.txt` (другие сайты — по адресу).
- Можно выбрать «Все сайты» — тогда все cookies попадут в один `cookies.txt`.
- Берёт в том числе скрытые (httpOnly) cookies вроде `sessionid` и `auth_token`,
  в которых и лежит вход в аккаунт.

## Установка (Chrome, Edge, Яндекс Браузер)
1. Откройте страницу расширений: вставьте в адресную строку `chrome://extensions`
   (в Edge — `edge://extensions`) и нажмите Enter.
2. Включите справа вверху **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку
   `cookies-extension` (эту самую).
4. На панели справа от адресной строки появится значок расширения
   (кусочек пазла → закрепите его булавкой, чтобы был виден).

Firefox: установка чуть другая (`about:debugging` → «Этот Firefox» →
«Загрузить временное дополнение» → выбрать `manifest.json`). Временное
дополнение в Firefox исчезает после перезапуска браузера.

## Как пользоваться
1. Откройте сайт (например `tiktok.com`) и войдите в аккаунт.
2. Нажмите значок расширения → **«Сохранить TikTok.txt»**.
3. Выберите, куда сохранить (например «Загрузки»).
4. В Video Downloader: меню **«Аккаунты»** → площадка → **«Указать файл
   cookies…»** и выберите сохранённый файл.
5. Исходный файл из «Загрузок» потом удалите — в нём ваш вход, как пароль.

## Безопасность
- Cookies = вход в аккаунт. Храните файл как пароль и не пересылайте никому.
- Лучше использовать не основной аккаунт: площадки иногда ограничивают
  аккаунты за частые автоматические скачивания.
- Хотите убедиться, что ничего не утекает? Весь код — три коротких файла
  (`manifest.json`, `popup.html`, `popup.js`), их можно прочитать целиком.
  Строки `fetch`/`XMLHttpRequest` в них отсутствуют.
